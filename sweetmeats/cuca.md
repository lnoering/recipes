# Massa

## Ingredientes

- [ ] Açúcar                // 1 Colher de Sopa
- [ ] Fermento Biológico    // 1 Colher de Sopa
- [ ] Água Morna            // 200ml
- [ ] Azeite de Oliva       // 2 Colher de Sopa
- [ ] Trigo                 // 2 Xícaras

## Processo

- Pegar uma bacia.
- Colocar a água morna e o fermento (deixar agir por 3 a 5 minutos)
- Adicionar meia xícara de trigo e mexer bem. (Repetir esse processo até acabar o trigo)
- Sovar com as mãos
- Deixar a massa descansar por 30 minutos ou até dobrar de tamanho.

# Cobertura

## De Maçã

### Ingredientes

- [ ] Maçãs                 // 3 unidades
- [ ] Açücar                // 2 colher de sopa
- [ ] Canela                // 1 colher de chá
- [ ] Amido de Milho        // 1 colher de sopa

### Processo

- Descascar as maçãs
- Cortar em Cubos
- Colocar em um recipiente e misturar tudo

## De Farofa

### Ingredientes

- [ ] Trigo                 // 1/2 + 1/4 de uma xícara
- [ ] Aveia                 // 1/4 de uma xicara 
- [ ] Açúcar                // 1/4 de uma xícara
- [ ] Canela                // 1 colher de chá
- [ ] ( Óleo ou manteiga ) de Coco // 3 colheres de sopa

### Processo

- Misturar tudo bem.

# Processo Geral

- Colocar a [massa](#massa) em uma forma.
- Deixar descansar por 25-30 minutos
- Colocar o [Recheio](#recheio) diretamente em cima da massa.
- Colocar a [cobertura](#cobertura) por cima do recheio.
- Levar para o forno a 180˚ graus por 35-40 minutos.
