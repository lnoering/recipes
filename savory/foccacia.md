# Massa

### Ingredientes

- [ ] Fermento Biológico    // 10g (2 Colheres de sopa)
- [ ] Trigo                 // 500g 
- [ ] Água Morna            // 280ml (15 minutos no microondas)
- [ ] Açúcar                // 3 Colheres de Sopa
- [ ] Azeite de Oliva       // 1/2 Xícara
- [ ] Sal                   // 1 colher de sopa

### Processo

- Pegar uma bacia.
- Colocar a água morna, fermento, 1/3 de xícara do trigo e o açücar.
- Misturar bem.
- Esperar 15 minutos.
- Adicionar o sal, azeite de oliva.
- Adicionar o Trigo aos poucos, e ir mexendo a massa em movimentos circulares, até ela ficar pegajosa.
- Coloque um pano por cima, e aguarde 30 minutos. (Caso queira, também pode armazenar na geladeira e fazer o resto no dia seguinte.)


# Cobertura

### Ingredientes

- [ ] Flor de Sal           // 2 - 3 pitadas (a gosto)
- [ ] Tomate cereja         // 500g
- [ ] Azeitona              // 200g
- [ ] Cebola                // 1 cebola grande
- [ ] Orégano               // 2 colher de sopa

### Processo

- Picar o tomatinho em rodelinhas.
- Picar a cebola em meia lua.
- Picar a azeitona em cubinhos pequenos.
- Salpique a flor de sal em cima da massa.
- Coloque a azeitona, cebola, tomate e o orégano.


# Processo Geral

- Transfira a [massa](#massa) para uma assadeira.
- Com as pontas dos dedos, faça oequenos bolsos na massa, como se fosse fazer buracos, porém não fure a massa.
- Colocar a [cobertura](#cobertura) por cima da massa.
- Levar para o forno pré-aquecido a 200˚ graus por 30 minutos, até que a massa fique dourada.
